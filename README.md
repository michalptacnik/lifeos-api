# LifeOS API

Modular monolith backend for LifeOS using Node.js, TypeScript, Express, Prisma, and PostgreSQL.

## Domain Modules
- Authentication & Authorization
- Tasks
- Budgets & Cashflow
- Inventory
- Recurring Obligations
- Notifications
- Audit Logging

## Quick Start
```bash
npm install
cp .env.example .env
npm run prisma:generate
npm run dev
```
